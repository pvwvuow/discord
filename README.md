# آینه‌ی فریم — discord.tvframe.vip

این مخزن **آینه‌ی کامل سایت فریم** است که روی `discord.tvframe.vip` سرو می‌شود.

## چطور کار می‌کند؟

| جزء | نقش |
|---|---|
| `mirror-sync.yml` | هر ۶ ساعت محتوای `docs/` مخزن اصلی [pvwvuow/frame](https://github.com/pvwvuow/frame) را اینجا کپی می‌کند |
| `CNAME` | دامنه‌ی سفارشی `discord.tvframe.vip` (دست‌نخورده نگه داشته می‌شود) |
| GitHub Pages | محتوا را روی دامنه‌ی آینه سرو می‌کند |

## نکته‌ها

- محتوای واقعی سایت فقط در مخزن اصلی (`pvwvuow/frame`) ویرایش می‌شود؛ اینجا خودکار همگام می‌شود و نیازی به ویرایش دستی نیست.
- اجرای فوری همگام‌سازی: تب **Actions → mirror-sync → Run workflow**.
- کلاینت دسکتاپ فریم کاورها و SITE را از همین دامنه می‌خواند.
